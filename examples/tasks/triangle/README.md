# Задача «Треугольник» без ветвлений

Признак d > 0 выражается без ветвлений: d строго положителен, когда `-d`
отрицателен, то есть знаковый бит `-d >> 63` равен 1 (в 64-битной арифметике
это дает маску -1). AND трёх масок - ответ: 0 или -1.

Проверка вручную через **RISC-V: Run Function** с аргументами, например
`3, 4, 5` -> `-1` (ненулевое), `3, 4, 7` -> `0`.
