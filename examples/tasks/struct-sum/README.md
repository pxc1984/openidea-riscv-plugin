# Задача «Сумма полей структуры»

`process` проходит массив `Elem` (stride 24 байта: `count` @0, `data` @8,
`summ` @16) и пишет в `summ` младшие 32 бита суммы — поэтому итог хранится
`sw`, а не `sd` (верхняя половина поля не нужна и могла бы затереть соседние
данные при другом паддинге).

Проверка: **RISC-V: Run File** — main печатает `10` и `35`.
